# Roof Groove 1.1.2 – ملاحظات التعديل

## اللي اتعمل
1. **الإصدار** اتغيّر من 1.1.1 إلى 1.1.2 (project.godot + app_version.gd + شاشة القائمة + ملفات الاستخراج).
2. **اللوجوهات/الأيقونات**: أيقونة المشروع كانت بتشاور على ملف مش موجود (uid ميّت) فكانت بتضيع في الاستخراج. اتصلّحت، واتعمل `icon.ico` للويندوز و`icon_512.png` و`icon_1024.png` للـ iOS.
3. **ملفات الاستخراج**: `export_presets.cfg` جديد لـ Windows / Linux / Android / iOS (الأيقونات والصلاحيات وأرقام الإصدار جاهزة، وصلاحية الإنترنت متفعّلة على أندرويد).
4. **الأونلاين P2P**: مفيش سيرفر مركزي. اللي يعمل الغرفة هو المضيف، والباقي بيدخلوا بكود الغرفة (11 حرف/رقم). عدد اللاعبين مش محدود (الحد الفعلي 4000 من ENet). البورت 24680/UDP بيتفتح تلقائي (UPnP).
   - تم حذف السيرفرات القديمة وشاشة "Phone Server".
   - لوحة الصدارة بقت محلية على الجهاز (ترتيب الـ Checkpoints العالمي لسه في ACCOUNT).
5. **الحساب**: رسائل الأخطاء بقت بتوضح السبب الحقيقي (DNS / TLS / مفيش اتصال) بدل "no internet" لأي خطأ.
6. **جوجل**: تسجيل بيرجع للعبة لوحده من غير كود (محتاج Desktop client – تحت). من غيره بيشتغل بالكود القديم لكن بيفتح المتصفح وينسخ الكود تلقائي.
7. **ديسكورد**: زر جديد (محتاج إعداد – تحت).
8. ترجمة عربي/فرنسي للنصوص الجديدة.

## اللي لازم تعمله إنت
### جوجل بدون كود
Google Cloud Console (نفس مشروع roof-groove) > Credentials > Create OAuth client ID > **Desktop app**. حط الـ ID والـ Secret في `scripts/firebase_config.gd` (`GOOGLE_DESKTOP_CLIENT_*`).

### ديسكورد
1. discord.com/developers/applications > OAuth2: فعّل **Public Client** وضيف Redirects: `http://127.0.0.1:53682/callback` وكمان 53683 و53684 و53685.
2. لو مشروعك على Spark، استخدم الخادم البديل داخل `vercel_discord_auth/README_AR.md`. ارفع مجلد `vercel_discord_auth` إلى Vercel، وأضف `DISCORD_CLIENT_ID` و`FIREBASE_SERVICE_ACCOUNT` كمتغيرات بيئة سرية هناك.
3. بعد النشر، حط رابط `https://اسم-مشروعك.vercel.app/api/discordLogin` في `DISCORD_LOGIN_URL` داخل `RoofGroove/scripts/firebase_config.gd`. لا تضع مفتاح خدمة Firebase في ملفات اللعبة أو GitHub.

### الاستخراج
- افتح المشروع بـ **Godot 4.7.2** (أول فتح بيعمل import، دقيقة تقريباً).
- أندرويد: Project > Install Android Build Template (لازم عشان إضافة الإشعارات)، وحط الـ keystore في الـ preset. غيّر `package/unique_name` لو نشرت قبل كده بـ id تاني.
- iOS: الاستخراج لازم من ماك + Xcode، وحط الـ Team ID. مفيش طريقة تانية.

## حدود لازم تعرفها
- **P2P**: لو راوتر المضيف مش بيدعم UPnP أو شركة الإنترنت عندها CGNAT، اللي من بره شبكته مش هيعرفوا يدخلوا (اللعبة بتنبّه المضيف). الحل: فتح البورت يدوي أو شبكة تانية.
- **تسجيل جوجل جوه اللعبة نفسها**: جوجل بتمنع نوافذ الويب المدمجة، فالمتصفح بيتفتح ويرجع للعبة تلقائي. ده أقرب حل مسموح.
- **ما اتجرّبش**: معنديش Godot هنا، فالتعديلات اتراجعت يدوياً وبفحص ثابت بس (مفيش دوال/ملفات ناقصة). جرّب بنفسك وابعتلي أي خطأ يظهر في الـ Output.
- ما لقيتش سبب أكيد لمشكلة "الحساب بيشتغل في المحرر وبيقف بعد الاستخراج"؛ الأرجح صلاحية الإنترنت على أندرويد (اتحلّت) أو خطأ TLS/DNS، ودلوقتي هيظهر بوضوح في شاشة الحساب.
- ملف `firebase_config.gd` فيه مفاتيح وسر Google Client قديم مكتوبين في اللعبة؛ اللي في الاستخراج بيتفك بسهولة (زي ما اتفك مشروعك). ما تحطش فيه أسرار حقيقية.
